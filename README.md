# Complain-management-app-frontend
CampusCare – Smart College Complaint Management System | A frontend-only web application built using HTML, CSS, and JavaScript for submitting, tracking, and managing college complaints.
Features
🔐 Student Login & Registration – Secure-looking login and registration interface for students.
📊 Interactive Dashboard – Displays total, pending, in-progress, and resolved complaints.
📝 Submit Complaints – Students can submit complaints with title, description, category, priority, and location.
📋 My Complaints – View and manage previously submitted complaints.
🔎 Search & Filter – Search complaints and filter them by status and category.
📈 Complaint Status Tracking – Track complaints through Submitted, Under Review, In Progress, and Resolved stages.
🔔 Notifications – Displays complaint-related status and submission notifications.
👤 Student Profile – View and edit student profile information.
🤖 Smart Category Suggestion – JavaScript-based smart suggestion for complaint categories.
⭐ Priority Suggestion – Suggests complaint priority based on the complaint description.
🖼️ Image Upload & Preview – Attach an image while submitting a complaint.
💾 Local Storage – Stores frontend demonstration data using browser localStorage.
📱 Responsive Design – Works across desktop, tablet, and mobile screens.
🎨 Modern UI/UX – Clean dashboard, cards, navigation, status badges, modals, and toast notifications.
🚪 Logout Functionality – Allows users to safely end their current session.
